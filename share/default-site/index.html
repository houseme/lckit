LCKit 默认站点

Linux + Caddy Kit 已部署。此页面是安装后的静态默认站，可继续创建业务站点或反向代理。

静态站点

托管前端构建产物或纯 HTML。

lckit site add -d example.com -t static

HTTP 反向代理

对接 Go / Rust / 任意本机 HTTP 服务，WebSocket 自动可用。

lckit site add -d api.example.com -t proxy --upstream http://127.0.0.1:8080

应用 systemd

把二进制注册为服务单元。

lckit app add --name api --bin /opt/api/api --port 8080

镜像源

official / tuna / aliyun / ustc，随时切换。

lckit mirror set tuna
